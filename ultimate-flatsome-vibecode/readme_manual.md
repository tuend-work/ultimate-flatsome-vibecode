Thư mục này chứa bộ skill Antigravity AI hỗ trợ cho plugin Ultimate Flatsome VibeCode.
Dùng Antigravity và Agent AI tích hợp sẵn để tạo mới, clone hoặc kiểm tra chất lượng landing page trên WordPress.

### Bộ 3 Skill Chính (Kèm file .md hướng dẫn):
1. **`clone-landingpage.py` & `clone-landingpage.md`**:
   - Clone bất kỳ URL nào về WordPress với độ tương đồng 90% đến 100% về hình ảnh, giao diện, nội dung, layout, icon.
   - Tự động cào ảnh, upload WordPress Media, map URL, nén CSS chống wpautop.
2. **`create-landingpage.py` & `create-landingpage.md`**:
   - Tạo landing page mới chuẩn SEO & High-converting từ file HTML, prompt hoặc cấu hình JSON Modular Section.
3. **`recheck-url.py` & `recheck-url.md`**:
   - Chạy tự động sau khi clone hoặc create. Kiểm tra 0 shortcode lỗi, 100% ảnh hợp lệ, CSS không bị wpautop làm hỏng, chụp 1 ảnh full page và lặp lại recheck cho đến khi đạt điểm chuẩn 90-100%.

### File Cấu Hình:
- `vbc-config.json`: Chứa thông tin kết nối API và tài khoản WordPress đích.
